# Privacy Policy

**App Name:** Octos

## Data Collection
This app does **not** collect or transmit any personal information from users.

## Data Usage
Octos renders HTML content, including files bundled with the app and files downloaded or provided by the user.  
When rendering web content, the app may send and receive data as part of normal web page loading (e.g., HTTP requests, assets, scripts).  
The app does not track or transmit any personal information outside the user's system beyond what the web content itself requires.

## Third-party Software
The app may require the Microsoft WebView2 Runtime, which the user must install if it is not already present.  
No other third-party software collects data on behalf of Octos.
